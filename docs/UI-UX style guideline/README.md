# TaskFlow UI/UX Design System Guidelines

TaskFlow delivers a sleek, modern, glassmorphic dark-mode dynamic experience designed for high productivity.

## Core Design Tokens

### Color Palette
- **Background Deep**: `#090d16`
- **Surface Dark**: `#111827`
- **Surface Glass**: `rgba(17, 24, 39, 0.7)` with `backdrop-filter: blur(12px)`
- **Accent Primary**: `#6366f1` (Indigo 500)
- **Accent Secondary**: `#8b5cf6` (Purple 500)
- **Text Main**: `#f9fafb`
- **Text Muted**: `#9ca3af`

### Typography
- **Primary Font**: `Inter`, sans-serif
- **Heading Font**: `Outfit`, sans-serif

### UI Micro-Animations
- Smooth hover elevation: `transition: all 0.2s cubic-bezier(0.4, 0, 0.2, 1)`
- Subtle button active scaling: `active:scale-[0.98]`
